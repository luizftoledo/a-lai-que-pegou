Como fazemos

A cada rodada, consultamos o BuscaLAI, a base de precedentes da CGU e os dados abertos de pedidos. Lemos a resposta oficial e os anexos relevantes antes de selecionar uma história. Cada item traz a íntegra, uma explicação do interesse público e uma pista concreta para a próxima apuração.

De 1º a 7 de outubro de 2026, a revisão é diária. Depois, semanal. Se uma fonte não permitir confirmar os documentos, a edição espera; o arquivo publicado continua disponível.
