Método

Como fazemos

1

Consultamos as bases

A cada rodada, buscamos no BuscaLAI, na base de precedentes da CGU e nos dados abertos de pedidos.

2

Lemos a íntegra

Lemos a resposta oficial e os anexos relevantes antes de selecionar uma história.

3

Entregamos a pista

Cada item traz a íntegra, uma explicação do interesse público e uma pista concreta para a próxima apuração.

A revisão é semanal, às segundas-feiras. Se uma fonte não permitir confirmar os documentos, a edição espera; o arquivo publicado continua disponível.
